# Color Palette

This document outlines the color tokens and inline color-override conventions used across `enterprise-ui` components and building blocks. Because Tailwind v4 is paired with inline `style` overrides in interactive components and building blocks, custom colors passed via component props (such as `bgColor`, `borderColor`, `textColor`, `mutedTextColor`, `activeColor`, `trackBg`, `indicatorBg`, `menuBg`, `itemHoverBg`, `headerBgColor`, `footerBgColor`, and `backdropColor`) are applied directly via inline styles rather than relying on dynamic Tailwind classes.
