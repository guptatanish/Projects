# Typography

The enterprise library uses **Inter** as the standard sans-serif typeface, optimized for highly legible data tables and application interfaces.

**Font Family:** `Inter`, `ui-sans-serif`, `system-ui`, `sans-serif`  
**Weights:** Regular (400), Medium (500), SemiBold (600), Bold (700)

<br />
